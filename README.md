# Factors Influencing Depression Among University Students

Power BI Analysis of 4464 University Students

## Overview
Depression Rate: 26.9% (1K depressed)

## Key Findings
- Health Condition Critical = 100% depressed
- Single students = 35.9% depression rate
- Low CGPA group = 39.2% depression rate
- Lower Middle class = 30.6% vs Rich = 17.6%
